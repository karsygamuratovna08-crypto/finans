# Мои финансы 🏰

Сказочный сайт для учёта личных доходов и расходов в тенге (₸).

## Возможности

- Добавление и удаление записей о доходах и расходах
- Отдельные категории для доходов и расходов, можно добавлять свои
- Баланс за выбранный месяц и расходы по категориям
- Кнопка «Отчёт за день» с итогами и разбивкой по категориям
- Оформление в сказочном стиле: ночное небо, звёзды и золотой замок

## Как запустить

Откройте файл `index.html` в браузере. Больше ничего устанавливать не нужно.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в него файлы `index.html`, `README.md` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через минуту сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Где хранятся данные

Данные сохраняются в браузере (localStorage) на том устройстве, где открыт сайт. На другом устройстве или в другом браузере записей не будет. Если очистить данные браузера, записи пропадут.
